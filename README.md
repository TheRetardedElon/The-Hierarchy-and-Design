# The Hierarchy and Design

Force-directed cluster map of the X Hierarchy Hunt (508 accounts, 514 edges as of 30 Aug 2026).

## Open

Open index.html in a browser. Graph data is embedded so a local file works with no server.

## Map

- Nodes colored by cluster
- Edges are verified-follower and dummy-walk links
- Confirmed seed is larger, with a gold ring
- Scroll to zoom, drag to pan, click a node for details

## Labels

- Puppet Masters: same verified handle on two dummy or seed trees
- Puppets: leftover-name / hybrid masks under a master
- Zombies: straight auto bots
