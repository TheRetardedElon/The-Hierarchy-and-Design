# The Hierarchy and Design

Force-directed cluster map of 32 accounts from a 29 Aug 2026 video walk.

## Open

Open `index.html` in a browser. It is self-contained (graph data is embedded), so a local file works with no server required.

Or serve it:

    npm install && npm start

Then visit http://localhost:4173

## Map

- Nodes colored by cluster
- Edges are verified-follower links from the walk
- Confirmed seed is larger, with a gold ring
- Scroll to zoom, drag to pan, click a node for details
